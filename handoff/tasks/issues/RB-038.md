# [RB-038] Implement paired portals and exit validation

**Scope:** mvp · **Milestone:** M3 · **Priority:** P1 · **Relative size:** L

**Owner role:** Gameplay

## Outcome

Teleport predictably with direction mapping and no recursive trigger loop.

## Implementation

1. Define entry/exit coordinate convention and mapped velocity.
2. Add radius-clearance checks, per-pair latch, and leaving-trigger condition.
3. Validate counterpart IDs and unobstructed exits.

## Acceptance criteria

- [ ] One pair preserves allowed speed and maps direction as designed.
- [ ] Ball cannot repeatedly teleport while inside an exit.
- [ ] Invalid pair/blocked exit fails validation or safely rejects entry.

## Required evidence

Portal unit/integration tests and visual pairing review.
