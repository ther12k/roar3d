# [RB-009] Create level wrapper and scene-marker contract

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** S

**Owner role:** Gameplay

## Outcome

Define the reusable authored level scene used by all holes.

## Implementation

1. Create wrapper nodes for visuals, collision, Spawn, Cup, kill region, bounds, and safe anchors.
2. Set collision-layer names and validate mandatory markers.
3. Separate imported GLB art from gameplay-owned collision/scripts.

## Acceptance criteria

- [ ] A minimal scene loads by validated ID.
- [ ] Missing required markers produces an actionable validation error.
- [ ] Reimported art does not overwrite gameplay nodes.

## Required evidence

Example graybox scene and validator output.
