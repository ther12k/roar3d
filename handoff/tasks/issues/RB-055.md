# [RB-055] Create reproducible signed Android release candidate

**Scope:** mvp · **Milestone:** M4 · **Priority:** P0 · **Relative size:** M

**Owner role:** Release Engineering

## Outcome

Produce the actual tested release artifact with secure signing and exact toolchain records.

## Implementation

1. Configure publisher-owned identifier, release export, and secure signing.
2. Capture build/SDK/template versions and artifact checksums.
3. Install the signed candidate and repeat offline/permission/save smoke tests.

## Acceptance criteria

- [ ] No production secrets are in Git or the handoff package.
- [ ] Release build, not only debug, passes critical smoke tests.
- [ ] Artifact version and source commit are traceable.

## Required evidence

Signed artifact metadata/checksum and release smoke report.
