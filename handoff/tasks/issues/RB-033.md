# [RB-033] Polish Ready/Capturing/Rolling gameplay HUD

**Scope:** mvp · **Milestone:** M2 · **Priority:** P1 · **Relative size:** M

**Owner role:** UI

## Outcome

Make the playfield and shot affordances readable on phones.

## Implementation

1. Build compact hole/par/stroke/pause header and bottom tray.
2. Separate live level from committed Shot power and render cancel/disabled states.
3. Adapt framing and controls for safe areas/narrow screens.

## Acceptance criteria

- [ ] Cup/ball/landing area are not hidden by decorative logo or HUD.
- [ ] Rolling state does not display misleading mic activity.
- [ ] Input fallback and Overview are discoverable.

## Required evidence

Portrait/narrow/tablet state captures.
