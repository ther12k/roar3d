# [RB-049] Externalize strings and prepare English/Indonesian localization

**Scope:** mvp · **Milestone:** M3 · **Priority:** P1 · **Relative size:** M

**Owner role:** UI/Content

## Outcome

Keep all interface copy editable and localizable rather than baked into art.

## Implementation

1. Move UI strings and errors into stable localization keys.
2. Complete English and review Indonesian translations when available.
3. Test longer strings and number formatting at narrow width.

## Acceptance criteria

- [ ] No important instruction exists only in a texture.
- [ ] Missing keys are detected automatically.
- [ ] No clipping or mixed-language accidental fallback in selected locale.

## Required evidence

Localization key audit and language captures.
