# [RB-014] Implement support, rest detection, and safe anchors

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** M

**Owner role:** Gameplay

## Outcome

Allow shooting only after real supported rest and record recoverable positions.

## Implementation

1. Apply speed/angular/support-duration thresholds.
2. Validate anchor slope, clearance, and distance from hazards.
3. Exclude moving surfaces, cup, portals, and pads from safe resting anchors.

## Acceptance criteria

- [ ] A midair apex or slowly sliding slope does not become Ready.
- [ ] Ball can settle reliably on intended turf.
- [ ] Unsafe/blocked anchors fall back to an authored checkpoint.

## Required evidence

Rest/anchor integration tests.
