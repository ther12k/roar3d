# [RB-008] Implement authoritative gameplay state machine

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** M

**Owner role:** Gameplay

## Outcome

Centralize shot acceptance, token invalidation, stroke ownership, and terminal events.

## Implementation

1. Implement documented states and guarded transitions.
2. Queue immutable commands for the physics tick and reject duplicate shot IDs.
3. Handle cancellation before commit and coalesce cup/fall terminal events.

## Acceptance criteria

- [ ] Duplicate release produces at most one shot/stroke.
- [ ] Background before physics commit cancels without a spent stroke.
- [ ] Only GameSessionController writes stroke totals and result state.

## Required evidence

Transition tests with fake input and clock.
