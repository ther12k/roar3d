# [RB-039] Implement one-shot bounce pad

**Scope:** mvp · **Milestone:** M3 · **Priority:** P1 · **Relative size:** M

**Owner role:** Gameplay

## Outcome

Create a reusable pad without per-frame energy accumulation.

## Implementation

1. Add authored impulse vector/strength and contact latch.
2. Coordinate compression/pulse visual with actual impulse.
3. Apply speed containment and test side/slow/repeated entries.

## Acceptance criteria

- [ ] One eligible entry produces one impulse.
- [ ] Remaining inside the trigger does not continue acceleration.
- [ ] Pad effect remains readable in reduced quality/motion.

## Required evidence

Pad regression scene and event-count tests.
