# [RB-022] Implement preview power and stable release selection

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** M

**Owner role:** Audio/Gameplay

## Outcome

Ensure displayed Shot power is precisely the value committed on release.

## Implementation

1. Implement frame-time-aware smoothing and 250 ms recent window.
2. Require at least 150 ms valid data and calculate the 75th percentile preview.
3. Expire stale preview and publish validity separately from live level.

## Acceptance criteria

- [ ] Preview-to-command difference is <=0.01 for accepted releases.
- [ ] A single transient/no-signal hold cannot launch.
- [ ] Frame-jitter and stale-buffer fixtures pass.

## Required evidence

Window/quantile tests and debug value comparison.
