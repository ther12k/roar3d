# [RB-050] Verify accessibility, reduced motion, and equal Touch path

**Scope:** mvp · **Milestone:** M4 · **Priority:** P0 · **Relative size:** M

**Owner role:** QA/UI

## Outcome

Ensure sound, motion, or voice ability is never a gate to completion.

## Implementation

1. Run full Touch/no-sound/reduced-motion journeys.
2. Check logical target sizes, visual/text state cues, safe areas, contrast, and focus.
3. Document supported accessibility behavior honestly.

## Acceptance criteria

- [ ] All content/rewards accessible without microphone.
- [ ] Color/audio/haptics are not the sole carrier of critical instructions.
- [ ] No unsupported blanket accessibility compliance claim is made.

## Required evidence

Accessibility checklist, screenshots, observed limitations.
