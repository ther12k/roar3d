# [RB-046] Implement content catalog and scene validators

**Scope:** mvp · **Milestone:** M1 · **Priority:** P1 · **Relative size:** M

**Owner role:** Tools

## Outcome

Catch content errors before they appear as broken gameplay.

## Implementation

1. Validate JSON schema plus unique IDs/order/count/path/known mechanics.
2. Inspect required scene markers, safe anchors, portal pairs, and exit clearance.
3. Separate design metadata validation from real scene/solvability evidence.

## Acceptance criteria

- [ ] Design-only catalog cannot be mislabeled production-validated.
- [ ] Missing scene or marker fails the shipping build gate.
- [ ] Every error reports level ID and actionable detail.

## Required evidence

Valid/invalid fixtures and build-gate output.
