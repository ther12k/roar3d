# [RB-003] Benchmark Mobile and Compatibility renderers

**Scope:** mvp · **Milestone:** M0 · **Priority:** P0 · **Relative size:** M

**Owner role:** Rendering

## Outcome

Choose a measured mobile rendering baseline before producing final course art.

## Implementation

1. Build a representative turf/island/ball/light/particle test scene.
2. Compare release-like builds with Mobile and Compatibility on the matrix.
3. Record frame-time distribution, memory, visual differences, and selected baseline.

## Acceptance criteria

- [ ] Decision includes measured p95/p99 data, not only average FPS.
- [ ] Target/low tiers are named with limitations and renderer-specific concerns.
- [ ] No renderer switch is hidden inside an ordinary graphics-quality toggle.

## Required evidence

Benchmark scene, raw metrics, comparison screenshots, renderer ADR.
