# [RB-035] Implement truthful results and save-warning UI

**Scope:** mvp · **Milestone:** M2 · **Priority:** P1 · **Relative size:** M

**Owner role:** UI

## Outcome

Show earned progress without invented voice-quality statistics or fake durable saves.

## Implementation

1. Build celebration, stars, strokes/par, progress, Next/Retry/Map.
2. Handle final hole and failed-attempt variants.
3. Expose save retry/warning on persistence failure.

## Acceptance criteria

- [ ] No whisper %, accuracy %, gems, or time-based rank is shown.
- [ ] Final hole routes to map/completion instead of a missing next scene.
- [ ] Save failures are visible and previous durable progress stays safe.

## Required evidence

Result variants and failure-injection tests.
