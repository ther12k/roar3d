# [RB-034] Implement Pause, Settings, and Android Back behavior

**Scope:** mvp · **Milestone:** M2 · **Priority:** P1 · **Relative size:** M

**Owner role:** UI/Platform

## Outcome

Create predictable navigation and preferences that cannot accidentally commit a shot.

## Implementation

1. Implement resume/restart/map and settings controls.
2. Handle back-stack order and confirmation when abandoning an attempt.
3. Persist preferences and cancel capture before mode changes.

## Acceptance criteria

- [ ] Resume never starts mic automatically.
- [ ] Back dismisses sheets before exiting gameplay.
- [ ] Volume/haptics/reduced-motion/quality/input settings persist.

## Required evidence

Back-stack/lifecycle tests and settings captures.
