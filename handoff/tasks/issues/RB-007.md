# [RB-007] Implement typed shot, score, and tuning domain contracts

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** S

**Owner role:** Gameplay

## Outcome

Create a pure shared contract for input power, physics impulse, and result scoring.

## Implementation

1. Implement ShotCommand/result data and normalized power-to-impulse helper.
2. Reject zero/non-finite/invalid input and validate horizontal direction.
3. Add scoring functions and versioned tuning resource.

- [ ] Boundary tests cover p=0, p=1, invalid numbers, and star thresholds.
- [ ] No UI, audio, or physics-node dependency exists in pure math functions.
