# [RB-020] Implement bounded VoiceInputService and silent monitoring

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** M

**Owner role:** Audio

## Outcome

Expose validated short-window digital sound levels without storing player audio.

## Implementation

1. Create capture provider with token ownership and fresh-frame readiness.
2. Use energy across both stereo channels and a bounded ring buffer.
3. Handle silence, non-finite values, clipping, no input, and overruns.

## Acceptance criteria

- [ ] No microphone sound is audible through output.
- [ ] Old frames cannot power a new capture session.
- [ ] No file/network/log path receives PCM.

## Required evidence

Synthetic tests, bus diagram, input lifecycle evidence.
