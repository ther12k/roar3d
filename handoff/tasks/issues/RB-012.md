# [RB-012] Implement complete Touch shot controls

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** S

**Owner role:** Gameplay/UI

## Outcome

Make the entire game playable independently of microphone access.

## Implementation

1. Create power slider, Shoot, disabled states, and input-mode intent.
2. Route Touch into the same ShotCommand as Voice.
3. Reject zero power and moving-ball shots.

## Acceptance criteria

- [ ] Touch can complete the graybox hole with mic permission denied.
- [ ] Same input value yields the shared impulse with no bonus/penalty.
- [ ] Shoot is unambiguous and never fires from slider release alone.

## Required evidence

Touch-only end-to-end test.
