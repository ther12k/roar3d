# [RB-011] Implement playfield aiming and input ownership

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** M

**Owner role:** Gameplay/UI

## Outcome

Provide intentional touch aim without UI fall-through or camera conflicts.

## Implementation

1. Map playfield drag to bounded horizontal aim.
2. Exclude UI hit regions and assign pointer ownership.
3. Draw a short obstacle-clipped direction guide, not an exact landing prediction.

## Acceptance criteria

- [ ] Dragging a UI control never changes world aim.
- [ ] Aim locks during capture and shot commit.
- [ ] Narrow-screen gestures remain usable with one thumb.

## Required evidence

Touch gesture tests and phone-scale recording.
