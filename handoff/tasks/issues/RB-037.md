# [RB-037] Implement moving gate obstacle

**Scope:** mvp · **Milestone:** M3 · **Priority:** P1 · **Relative size:** M

**Owner role:** Gameplay

## Outcome

Introduce visible timing puzzles with paused fixed-time motion.

## Implementation

1. Create an AnimatableBody3D gate with authored path/period/phase.
2. Match collision to visuals and communicate movement range.
3. Pause phase with gameplay and prevent impossible trapping layouts.

## Acceptance criteria

- [ ] Pause/resume does not teleport the obstacle.
- [ ] Low-speed contact and fast impact are stable.
- [ ] Gate can be reused by multiple holes without copied logic.

## Required evidence

Obstacle test scene and pause/impact tests.
