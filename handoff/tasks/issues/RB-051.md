# [RB-051] Build automated domain/state/scene regression suite

**Scope:** mvp · **Milestone:** M4 · **Priority:** P0 · **Relative size:** L

**Owner role:** QA/Engineering

## Outcome

Make the core contracts resistant to regressions during polish and content changes.

## Implementation

1. Automate unit fixtures for math, scoring, unlocks, saves, and invalid input.
2. Add fake-clock/input state tests and diagnostic scene tests.
3. Run headless import/parse plus content gates in clean CI.

## Acceptance criteria

- [ ] Tests fail intentionally when a contract is broken.
- [ ] Synthetic success is not reported as a passed hardware/GPU test.
- [ ] CI commands/toolchain are pinned and documented.

## Required evidence

CI runs, fixture inventory, intentional-failure demonstration.
