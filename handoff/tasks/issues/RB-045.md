# [RB-045] Implement validated local progress/settings and recovery

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** L

**Owner role:** Systems

## Outcome

Preserve completed progress through duplicate events and interrupted writes.

## Implementation

1. Implement schema validation, best-result merge, and derived unlocks.
2. Write/validate temp snapshots, preserve last-good backup, and check replacement errors.
3. Separate settings/calibration from progress and expose save failure status.

## Acceptance criteria

- [ ] Worse replay/duplicate completion never erases a best result.
- [ ] Truncated/future-schema/invalid values fail safely.
- [ ] Failure at each write step preserves a valid prior durable copy where available.

## Required evidence

Migration/merge fixtures and write-failure tests.
