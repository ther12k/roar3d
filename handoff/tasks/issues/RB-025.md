# [RB-025] Implement game audio ducking and nonverbal feedback

**Scope:** mvp · **Milestone:** M1 · **Priority:** P1 · **Relative size:** M

**Owner role:** Audio

## Outcome

Support gameplay feedback without contaminating voice measurement.

## Implementation

1. Add separate music/effects/microphone routing and capture ducking.
2. Trigger mascot roar and shot sounds only after capture closes.
3. Support volume, muted mode, and no mandatory audio cues.

## Acceptance criteria

- [ ] The game cannot power itself from its own UI/mascot sound in normal tests.
- [ ] Muted players can complete using visual cues.
- [ ] All audio has recorded provenance and no user voice clips.

## Required evidence

Mixer checks and speaker/headphone tests.
