# [RB-015] Implement out-of-bounds and stuck recovery

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** M

**Owner role:** Gameplay

## Outcome

Recover from falls predictably with one penalty and no infinite reset loop.

## Implementation

1. Coalesce kill-plane and kill-volume events by shot ID.
2. Reset through a safe physics state and clear residual velocity/forces.
3. Add explicit stuck-recovery option after the watchdog period.

## Acceptance criteria

- [ ] One fall adds exactly one penalty in addition to the committed shot.
- [ ] Repeated trigger events cannot create repeated penalties.
- [ ] Blocked safe anchor uses fallback; confirmed recovery does not silently erase score.

## Required evidence

Fall/reset/blocked-anchor tests and recording.
