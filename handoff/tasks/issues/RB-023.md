# [RB-023] Connect hold/release/cancel voice gestures

**Scope:** mvp · **Milestone:** M1 · **Priority:** P0 · **Relative size:** M

**Owner role:** Gameplay/UI

## Outcome

Deliver the complete intentional voice-shot interaction.

## Implementation

1. Implement warmup/listening UI states and initiating-pointer ownership.
2. Lock camera/aim during hold and add explicit cancel region.
3. Reject timeout, duplicate release, interruption, and invalid preview.

## Acceptance criteria

- [ ] One valid release adds one stroke and impulse.
- [ ] Cancel and >3 second hold never auto-fire.
- [ ] Secondary touches and UI navigation cannot create unintended shots.

## Required evidence

Gesture/state regression tests and phone recording.
