# Illustrative GDScript helpers

These two `.gd` files illustrate pure shared math for the proposed game. They are not a complete Godot project, scene, microphone provider, or production implementation.

They have not been parsed or executed by a Godot binary in this delivery. `tools/test_contracts.py` tests equivalent formulas and synthetic contracts in Python; that does not certify GDScript compilation or Android behavior. The implementation agent must port/review, parse in the pinned engine, add actual GDScript tests, and integrate the full state/lifecycle logic.

No Kotlin source is generated because the MVP has no demonstrated native capability gap. The conditional plugin contract is in `docs/09_ANDROID_KOTLIN_AND_BUILD.md` and task RB-048.
