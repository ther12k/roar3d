# Visual reference pack

Open `gallery.html` in a browser after extracting the whole ZIP. The seven full-resolution PNGs in `references/` are the previous concept images from this conversation. No new scenes were generated in this documentation task.

The gallery includes the intended implementation changes for each screen. The authoritative MVP behavior is in `docs/06_UI_UX_SPEC.md`: two worlds, twelve holes, three cosmetics, no economy, and equal Voice/Touch gameplay.

These are concept references, not editable Figma files, layered assets, or real-time Godot screenshots. Rebuild the 3D scenes with models and the interface with Godot Controls. No font binaries, production GLB files, or music assets are included.
